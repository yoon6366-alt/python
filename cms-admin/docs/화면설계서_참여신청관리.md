### cms1. 정규수업 목록 페이지

| 번호 | 항목명 | Description |
|------|--------|-------------|
| 1 | 검색조건 | 개설연도, 노출여부 드롭다운 선택으로 목록 필터링 |
| 2 | 키워드 | 검색 카테고리(전체) 선택 후 검색어 입력, [검색] 버튼 클릭 시 결과 조회 |
| 3 | 등록일 | 날짜선택(캘린더) 또는 기간 버튼으로 등록일 범위 검색 |
| 3a | 기간 버튼 | 전체, 7일, 15일, 1개월, 3개월, 6개월, 1년 클릭 시 해당 기간으로 자동 설정 |
| 4 | 총건수/페이지 | 검색 결과 총 건수 및 현재 페이지 표시, 페이지당 표시 개수(10개) 선택 |
| 5 | 등록 | 클릭 시 **정규수업 등록** 페이지로 이동 |
| 6 | 목록 테이블 | 체크박스, No, 개설연도, 프로그램명, 신청기간, 신청 목록, 신청인원/모집정원, 설문통계, 조회수, 노출여부, 등록일시 컬럼 |
| 6a | No | 정규수업 고유 번호, 클릭 시 **정규수업 등록(수정)** 페이지로 이동 |
| 6b | 신청 목록 [상세보기] | 클릭 시 해당 정규수업의 **정규수업 신청** 목록 페이지로 이동 |
| 6c | 설문통계 [상세보기] | 클릭 시 해당 정규수업의 **설문조사 통계** 페이지로 이동 |
| 7 | 페이지네이션 | 페이지 번호 클릭으로 해당 페이지 목록 조회 |

### cms2. 정규수업 등록 페이지 (기본 정보)

| 번호 | 항목명 | Description |
|------|--------|-------------|
| 1 | 노출여부 * | 라디오 버튼 (노출 / 미노출), 사용자 페이지 노출 여부 설정, 필수 입력 |
| 2 | 개설연도 * | 드롭다운 선택 (현재 연도 기본값), 필수 입력 |
| 3 | 프로그램명 * | 텍스트 입력, 필수 입력 |
| 4 | 기간 * | 신청기간 및 수업기간 설정, 필수 입력 |
| 4a | 신청기간 | 시작일 ~ 종료일 캘린더 선택 |
| 4b | 수업기간 | 시작일 ~ 종료일 캘린더 선택 |
| 5 | 모집인원 * | 숫자 입력 (명), 필수 입력 |
| 6 | 썸네일 * | 이미지 파일 업로드, 필수 입력 |
| 6a | 파일 선택 | 파일 탐색기 열기 |
| 6b | 이미지 대체 텍스트 | 웹 접근성을 위한 alt 텍스트 입력 |
| - | 안내문구 | ★ 이미지 권장 비율은 A4, 권장 용량은 10MB 입니다. |
| 7 | 수업 기본정보 * | 테이블 형식 입력, 필수 입력 |
| - | 수업일정 | 텍스트 입력 |
| - | 수업대상 | 텍스트 입력 |
| - | 수강인원 | 텍스트 입력 |
| - | 재료비 | 텍스트 입력 |
| - | 수업장소 | 텍스트 입력 |
| 8 | 평일/주말 * | 라디오 버튼 (평일수업 / 주말수업), 필수 입력 |

## 📌 참고사항

1. **필수 입력 항목**은 라벨 옆에 `*` 표시
2. **★ 표시 문구**는 실제 서비스 적용 전 담당자 확인 필요
3. **밑줄 텍스트**는 클릭 가능한 링크를 의미
4. **회색 배경 영역**은 읽기 전용(수정 불가) 필드
5. **드롭다운 기본값**은 빈 값 또는 현재 연도로 설정
